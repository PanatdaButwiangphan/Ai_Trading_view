## ของที่คงจาก v1.64

แสดงสเปรดบนแผง, Block ชัดขึ้น (`spread too high (72 > 50)`), ปิดกำไรตามเวลา, วินัย ±10 USD, Input ภาษาไทย, Journal ปฏิทิน, SL/TP ออโต้

## วิธีใช้

1. SCALP: ชาร์ต **M1** → ลาก EA | GATES: ชาร์ต **H1** → ตั้งโหมดเทรด = **GATES**  
2. เปิด **Algo Trading** — แผงต้องขึ้น `Algo: ON`  
3. ดู `Spread: … / max … (auto)`, `Block:`, และ `Why:` ถ้าไม่เข้าไม้  
4. SCALP เข้าบ่อยขึ้นถ้า `InpScalpLooseEntry` เปิด (ค่าเริ่มต้น)  
5. ไม้มีกำไรแต่ไปไม่ถึง TP: ดูกลุ่ม **ปิดกำไรเมื่อไม่ถึง TP** / แผง `UTP`  
6. ทิศพลิกแล้วกลัวโดน SL เต็ม: ดูกลุ่ม **ตัดไม้เมื่อทิศสวน** / แผง `AdvCut`  
7. อยากได้แจ้งบนมือถือ: ตั้ง MetaQuotes ID + เปิด `InpPushOnSignal`  
8. โหมด GATES ถ้าอยากให้ดูแค่ 3 ด่าน: ปิด `InpUseMtfFilter` / `InpUseSwingFilter` ได้  

ถ้าสเปรดเกินบ่อย: ตั้ง **สเปรดสูงสุด (points)** ใน Inputs เป็นค่าที่ต้องการ (เช่น 40) หรือรอช่วงสเปรดแคบลง — ค่า `0` = ใช้ auto ตามคู่
