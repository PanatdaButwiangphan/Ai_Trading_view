# AiTradingView — EA สำหรับ Exness MT5 (v1.63)

> Copy + Compile จนหัวข้อขึ้น **`AiTradingView 1.63`**

## ของใหม่ใน v1.63

| ฟีเจอร์ | รายละเอียด |
|--------|------------|
| ปิดกำไรตามเวลา | ถ้าไม้ EA ถือเกิน **60 นาที** (ปรับได้) และกำไรลอย ≥ **0.50 USD** แต่ยังไม่ถึง TP → ปิดทำกำไรอัตโนมัติ ลดโอกาสโดน SL ทีหลัง |

## ของที่คงจาก v1.62

วินัย ±10 USD, Input ภาษาไทย, Trade permission, Panel Algo/Block, Journal, SL/TP ออโต้

## วิธีใช้

1. ชาร์ต **M1** → ลาก EA  
2. เปิด **Algo Trading** — แผงต้องขึ้น `Algo: ON`  
3. ดู `วินัย:` และ `TimeClose: 60m` บนแผง  
4. ปรับกลุ่ม **ปิดกำไรตามเวลา** ตามสไตล์เทรด

## Inputs ปิดกำไรตามเวลา (v1.63)

- เปิดปิดกำไรเมื่อถือนานเกินกำหนด (ค่าเริ่ม ON)  
- นาทีสูงสุดที่ถือถ้ายังกำไรแต่ไม่ถึง TP = **60**  
- กำไรลอยต่ำสุดถึงจะปิด (USD) = **0.50**  
- Alert เมื่อปิดด้วยกฎนี้  

หมายเหตุ: ปิดเฉพาะตอน**ยังกำไร** — ถ้าขาดทุนจะไม่บังคับปิดตามเวลานี้

## Journal

1. เปิด `InpJournalCsv`  
2. ไฟล์: **Data Folder → `Common\Files\AITV_journal.csv`**  
3. เปิด `web/journal.html` หรือ `web/index.html` → ลาก CSV  
4. ดู**ปฏิทินรายเดือน** — แต่ละวันโชว์กำไร (เขียว) หรือขาดทุน (แดง) + Net ของเดือน  
5. คลิกวันเพื่อกรองรายไม้ด้านล่าง  

### Deploy ขึ้น Vercel

Root Directory = **`web`** → Deploy → ลาก CSV เองบนเว็บ

## ติดตั้ง

1. MetaEditor → Data Folder → `MQL5\Experts\`  
2. ทับ `AiTradingView.mq5` → Compile (F7)  
3. ถอด EA เก่า → ลากใหม่ → ตรวจ **1.63**
